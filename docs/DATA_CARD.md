# کارت داده — inno-medical-eqm

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_eqm generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** ۱۲۰۰ دستگاه؛ برچسب خرابی از مدل لجستیک با نویز تولید می‌شود (قدرت سیگنال فرض است نه اندازه‌گیری).
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
